# AIChatbot Hotel Management

AI engineering layer for the existing Hotel Management backend.

## Architecture

Hotel Management Backend (existing, deployed separately)
        ↓
AI Chatbot Service
        ↓
OpenAI API

The backend remains unchanged. This repository contains only the AI layer.

## Current Goal

Build the AI system incrementally by applying the Associate AI Engineer for Developers career path to a real Hotel Management system.

The first milestone is a minimal OpenAI API integration.
